->Pourquoi le conteneur reste après un crash
Quand tu fais docker run, Docker crée un nouveau conteneur à partir de ton image. Si ce conteneur plante (comme ton FileNotFoundError), il s'arrête, mais il n'est pas supprimé automatiquement. Il reste "sur le disque" avec son nom, ses logs, son état — un peu comme un fichier fermé mais pas effacé.
Résultat : le nom fraud-agentai reste "réservé" par ce conteneur arrêté, donc si tu relances docker run --name fraud-agentai ..., Docker refuse car ce nom est déjà pris.

FraudGuard est une application de détection de fraude bancaire en temps réel qui analyse les transactions et les modifications de comptes bénéficiaires afin d'identifier les comportements suspects (ajouts massifs de bénéficiaires, transactions anormales, patterns de fraude), tout en réduisant les fausses alertes grâce à un moteur combinant règles métier et intelligence artificielle.

1. Cas d'usage à couvrir
Détection de fraude sur transactions
Montants inhabituels par rapport à l'historique du client
Transactions à des heures ou lieux atypiques (géolocalisation incohérente)
Vitesse anormale (plusieurs transactions en quelques secondes/minutes)
Transactions vers des comptes/pays à risque
Ajout massif de bénéficiaires
Seuil : X bénéficiaires ajoutés en Y minutes/heures → alerte
Bénéficiaires ajoutés puis transaction immédiate (pattern classique de fraude)
Bénéficiaires avec des IBAN/comptes déjà signalés dans une liste noire
Réduction des fausses alertes (faux positifs)
C'est souvent le vrai défi technique : un système trop sensible noie les analystes sous de fausses alertes

deploiement thehive
1. TheHive
TheHive est l'application principale de gestion des incidents de sécurité (IR/SOC).
2. Cassandra
Rôle : base de données principale.
TheHive stocke dans Cassandra :

Les alertes
Les cas (cases)
Les tâches
Les observables
Les informations utilisateurs

Pourquoi Cassandra ?

Haute performance en lecture/écriture.
Très bonne scalabilité.
Conçue pour gérer de gros volumes de données.

3. OpenSearch
Rôle : moteur d'indexation et de recherche.
OpenSearch permet :

La recherche rapide dans les alertes et cas.
Les filtres complexes.
Les tableaux de bord et statistiques.

Sans OpenSearch, les recherches seraient beaucoup plus lentes sur de grands environnements.
4. MinIO
Rôle : stockage des fichiers.
MinIO stocke :

Les pièces jointes.
Les captures d'écran.
Les rapports PDF.
Tout fichier uploadé dans TheHive.

Il fournit une API compatible Amazon S3, utilisée nativement par TheHive 5.
Pourquoi utiliser Docker Compose ?
Docker Compose permet de :

Déployer tous les services d'un seul coup.
Garantir la compatibilité des versions.
Simplifier les mises à jour.
Faciliter les tests et laboratoires SOC.
